# larpcorrupt

Vercel-ready Next.js site for **larpcorrupt / OxyEnv (claudmor)**.

## Run

```bash
npm install
npm run dev
```

The site expects the background track at `public/Fr3sh.mp3`. It starts only after the click-to-enter gesture, then loops with a mute/unmute control.

Discord: https://dsc.gg/oxyenv
